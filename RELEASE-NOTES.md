# ViceBounce 1.0.0

- One ASI for classic Vice City retail 1.0, retail 1.1 and Steam, with executable checks.
- **F11 opens the mod menu** in gameplay, vehicles and on pause. Choose **Change track** to import music. The game keeps running while you browse.
- **UK bounce curve:** the snappy Toyota Yaris meme style. Switch with **/** or **More settings → Bounce style**.
- Compact music controls, grouped vehicle/people/world effects, update notices and developer news with optional links. Updates open the release page; installation stays manual.
- **Grave (`)** or **Pause** pauses/resumes music in place. The pause state survives a settings reload.

**Controls have changed — check the [hotkey table](https://github.com/tek-95/ViceBounce#controls).**

Install the **Win32** [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader) first. Close the game, then copy the archive's `scripts` folder into the game folder. When updating, keep your existing `ViceBounce.ini`. The music importer requires Windows 10/11 x64; the ASI itself is 32-bit.

Music is not included. Press **F11 → Change track** to select your own file.
